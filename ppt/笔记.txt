人脸识别
====================================================================================
技术点/底层的算法模块：
    目标检测(目标检测+关键点检测) + 图像特征向量提取(图像分类、度量学习模型) + 向量检索(如何快速的从海量向量中获取和当前向量最相似的向量)
应用方向上来讲：
    -1. 人脸检测
    -2. 人脸检测 + 关键点检测 --> 人脸矫正
    -3. 人脸检测 + 关键点检测(可选) + 图像分类 --> 表情分析、年龄/性别/User-ID等分析
    -4. 人脸检测 + 关键点检测(可选) + 图像特征向量提取 --> 人证对比、人脸检索
应用比较多的场景:
        人证对比: 比较人和证件是否匹配；火车站/高铁站/飞机场等地方的自动检查、手机人脸解锁等
        人脸检索: 获取和当前人匹配的图像/信息；人脸考勤、人脸的闸机、人脸的支付等；
        eg:
            https://ai.arcsoft.com.cn/product/arcface.html
            https://www.media-smart.cn/productinfo/2987076.html?templateId=1133605

活体检测
    直白来讲就是判断当前摄像头前面的是否是真实的人脸
    常规的实现方式有:
        -1. 基于物体的特性进行判断：摩尔纹、颜色'照射'等方式 --> 正常的图像和视频、照片拍摄出来的图像是不一样的
            可以理解成，后台有一个分类模型，输入的就是一张图像，输出的就是这个图像是假人还是真人
            分类模型的训练：正样本就是真人的图像，负样本就是二次拍摄的图像
        -2. 基于动态进行判断是否属于真人，随机产生动作的要求，录制一小段视频，判断视频中的动作是否就是需要的动作要求
            后台存在一个模型，输入的是一小段视频(多张图像), 输出这段视频对应的动作

应用场景：
    1. 火车站的人脸安检、飞机场的人脸安检
        系统模块/功能1: 安检进站
            -1. 旅客将身份证放到感应器上，感应器获取身份证里面的信息：身份证号码、姓名等
            -2. 感应器往服务器发送请求，判断当前身份证对应人是否有购票记录<以及购票是否是最近24小时内的>、以及获取身份证对应的人脸图像特征向量
            -3. 感应器得到服务器的返回后(逻辑可以放到感应器上，也可以放到服务器里面)
                -3.1. 如果当前旅客由于各种原因限制，不允许进入候车厅，直接提示人工处理；
                -3.2. 如果当前车站购票大厅在安检后，那么直接进入人证对比步骤4
                -3.3. 如果当前车站购票大厅在安检前，需要先判断这个人有没有买好票(未来24小时的)，如果没有买好，直接拒绝进入；如果买好，那么进入人证对比步骤4
            -4. 感应器处理人证对比逻辑
                -4.1. 感应器调用摄像头获取当前图像
                -4.2. 感应器简单判断图像中是否有人脸区域(OpenCV)
                -4.3. 判断人证是否匹配
                    -4.3.1 方式一：将包含人脸区域的图像以及身份证号码传递给服务器，服务器判断这个包含人脸区域的图像里面的人脸和身份信息是否对应，并返回结果给感应器
                    -4.3.2 方式二：直接边缘端进行人脸对比
                    NOTE: 对比方式流程均一致：
                        -a. 从当前图像中获取当前人脸区域图像 --> 目标检测/单目标检测(人脸)
                            方式一：就一个单纯的目标检测
                            方式二：需要考虑活体目标检测(如果给定的输入数据中，不是活体，那么直接返回None；否则返回人脸区域图像)
                                判断当前图像中的人脸是否是活体<真正的人脸>
                        -b. 获取当前人脸图像对应的特征向量 --> 分类模型/度量学习模型
                        -c. 基于当前的人脸特征向量v1和数据库中该身份证对应的人脸特征向量v2，计算v1和v2的相似度sim --> 一般采用余弦相似度
                        -d. 如果相似度sim大于等于某个先验阈值，那么认为是匹配的，否则就是不匹配
                -4.4. 如果人脸匹配，直接打开通道
                -4.5. 如果人脸不匹配，重新执行步骤4，如果超过n次均不匹配，那么直接提示人工处理
        系统模块/功能2: 人脸图像录入
            12306的实名认证<以前：线下实名认证 --> 录入人脸图像，将人脸图像特征向量保存到数据库中>
    2. 人脸的考勤打卡
        主需求：摄像机拍摄人脸图像，然后从公司内部所有员工中，采用以图搜图的方式，检索出最相似/最匹配的员工以及匹配度/相似度，当匹配度超过设定阈值的时候，认为当前员工打卡成功。
		子功能：
			-1. 员工信息录入(入职)
				填写资料 --> 拍摄照片(n张) --> 调用模型提取每个照片对应的特征向量 --> 资料&特征向量保存数据库，并且特征向量构建向量索引库
			-2. 员工打卡
				摄像机一直开着的(视频流的形式) ---> 摄像机判断前方是否有物体信息发现变化(比较无物体时候的图像和当前图像之间的像素变化) --> 摄像机拍摄照片 --> 照片发服务器调用模型获取得到人脸向量 --> 人脸向量发送给向量检索服务器检索获取最匹配的员工id以及匹配度 --> 最大匹配度超过阈值的，基于员工id从数据库获取员工信息，并将该员工在当前时刻的打卡信息录入数据库 --> 员工信息返回摄像机端进行显示，并且打开门
			-3. 员工考勤记录统计
				从记录下来的员工打卡信息中提取每天员工最早打卡时间和最晚打开时间，按照既定规则计算实际上班时间并记录考勤状态
		功能中涉及到模型的部分：
			-1. 人脸检测功能：

					NOTE: SSD、YOLO等所有目标检测算法均可以；MTCNN的人脸检测算法。
			-2. 人脸特征提取功能：
				基于模型1提取的人脸区域，获取该区域内的人脸特征 --> 人脸特征向量提取
		    -3. 向量检索服务
		        从海量的向量库中，获取和当前向量相似的k个向量

车牌号码的识别/提取
    实现思路来讲：
        方式一：基于分类的思路实现
            在车牌号码区域识别的时候，同步加入关键点识别(识别四个点的坐标)，当识别出车牌的四个点坐标后，直接旋转(透视变换)变成一个正的车牌
            车牌中各个字符之间的大小是固定的，可以基于规则进行分割，从而形成一个一个单词字符串
            然后在针对每个单个字符建立分类模型进行预测即可
        方式二：基于目标检测的思路实现
            对检测出来的车牌区域图像进行第二次目标检测，当前检测的对应类别就是：字母 + 数字 + 省份 + 特殊文字；
            类似：手写数字的目标检测实现(识别出数字、 识别出具体数字是多少)
        方式三：可以直接采用OCR的方式 --> 判别模式 --> 内部本质上来讲还是一个分类模型
            OCR: 字符识别
                卷积(Conv) + CTC Loss
                卷积(Conv) + RNN/LSTM/GRU + CTC Loss
                卷积(Conv) + Attention/Transformer + CTC Loss
            完整的OCR一般采用的方式是:
                a. 先目标检测(检测文字，将文字区域框出来) + 水平矫正
                    可参考模型: YOLO体系、SegLink、SegLink++
                        https://github.com/dengdan/seglink
                        https://github.com/ZJULearning/pixel_link
                b. 在对文字所在的局部区域进行具体文字内容/具体文字的预测
                    可参考模型: Conv + Attention/Transformer --> ConvNextViT
        方式四：OCR的方式 + 生成模式 ---> 生成模型/图生文的结构
            多模态(VL)的一种结构
                一般来讲网络结构包含
                    图像的特征向量提取模块(ImageEncoder)
                    文本生成模块(TextDecoder)

前置知识点理解：
    1. 神经网络(Linear、Conv、RNN、LSTM、Attention、Transformer....)都在做特征提取，并且是基于训练神经进行反向传播拟合进行学习的
    2. Attention
        一种类似卷积的神经网络结构
        可以理解成是一种自适应的value合并的方式
        Attention中主要三个"角色":Q\K\V
            本质的需求是合并多个v
                方式一：最原始的方式就是(均值):
                    v = 1/3*v1 + 1/3*v2 + 1/3*v3
                方式二：将每个v对应的权重进行参数化(alpha其实就是模型参数)，让模型学习这个参数:
                    v = alpha1 * v1 + alpha2 * v2 + alpha3 * v3
                方式三: 每个v的权重应该和q/k相关(Attention)
                    alpha1=f(q,k1)
                    alpha2=f(q,k2)
                    alpha3=f(q,k3)
                    v = alpha1 * v1 + alpha2 * v2 + alpha3 * v3
        参考:
            https://blog.csdn.net/zwqjoy/article/details/120285123
            https://zhuanlan.zhihu.com/p/526155983
        NOTE:
            Attention中重点就是找出/确定Q、K、V分别是什么

AE: 自编码神经网络
    AE: Auto Encoder, 本身的目的是具有一定的降维(只使用编码器)、去噪(编码器 + 解码器)、图像生成(只使用解码器)等特征的网络结构
    VAE: Variational Autoencoder AE结构的一种发展，可用于图像生成领域
    参考：
        https://zhuanlan.zhihu.com/p/628604566?utm_id=0
        https://blog.csdn.net/weixin_43135178/article/details/130592568
        https://huggingface.co/spaces/belinghy/character-animation-motion-vaes
    NOTE:
        随机一个满足一定数据分布的特征向量，调用自编码器神经网络的解码器部分，获得一个随机的生成图像
        如果一个特征向量满足某种数据分布，就可以将其转换为数据分布对应的图像类别数据 / 如果给定的是具有某种语义的特征向量，那么对应的解码器输出图像应该就是满足这个语义的图像数据
    主体结构：
        编码器：负责将输入数据转换为高阶特征向量信息
        解码器：基于高阶特征向量/随机的特征向量恢复/构建输出图像

ViT: vision_transformer
    参考:
        https://github.com/google-research/vision_transformer
        https://arxiv.org/pdf/2010.11929.pdf
        https://modelscope.cn/models/iic/cv_vit-base_image-classification_Dailylife-labels/summary
        https://pypi.org/project/mmcls/
        https://mmclassification.readthedocs.io/en/latest/install.html
        https://docs.ultralytics.com/zh/models/rtdetr/#overview
    库依赖：
        pip install mmcls
        pip install -U openmim
        mim install mmcv-full
        ps: 如果还是安装出错，那么考虑使用Python3.9环境
    主要思路：
        -1. 将图像划分成单元格，将每个单元格/局部区域图像看出一个token，从而形成一个token的序列
        -2. 和Bert一样，在token的最前方加入一个特殊的token(cls) ---> 用来表示全局特征
        -3. 和Bert一样，给每个token向量增加一个位置编码，表示是第几个token/第几个局部区域
        -4. token对应的向量分别进行不同参数的全连接，得到Q、K、V；然后就可以通过Transformer结构来提取特征V的融合特征向量
        NOTE: 将每个局部区域与局部区域，计算相关性，并进行特征融合

        每个局部区域就是一个Token
        针对图像分类来讲，需要决策输出来判断输入哪个类别 --> 分类任务
        分类任务中是不是需要获取得到全局的特征向量
        卷积中常用的方式是:
            假定输入一个图像3*224*224的图像，经过一系列卷积之后，输出的特征为Z: 768*14*14
            在卷积神经网络为整体的图像分类模型中，这个使用针对Z会全局平均池化，变成: 768*1*1 -> 也就是得到了全局高阶特征向量
            最后在全连接得到属于各个类别的置信度(768 -> 1296)
        ViT中逻辑方式为:
            假定输入一个图像3*244*224的图像，经过一系列卷积之后，输出的特征为Z: 768*14*14
            接下来使用Attention/Transformer结构计算每个局部区域与局部区域之间的相关性(总共有14*14+1=197，每个区域的向量维度大小为768)
            然后针对每个区域，基于这个区域和所有区域之间的相关性计算权重值，然后将所有区域的特征向量v加权合并作为当前区域的特征向量 --> 针对每个区域都是这个操作
            然后再针对每个区域进行FFN全连接进一步提取当前区域的特征向量
            重复上述三个操作(提升模型的特征拟合能力)
            最后得到的就是最终的全局高阶特征向量(相比于之前普通卷积中平均池化的方式，此时这种特征融合是不是就增加了特征的自适应)
            最后在全连接得到属于各个类别的置信度(768 -> 1296)

            vit的计算逻辑:
                假定输入图像3*224*224，通过一系列卷积之后，得到的feature map为: 3*2*2
                这个时候，将feature map进行patch_token转换，得到4个token: T1、T2、T3、T4, 每个token的向量维度大小为3维
                在最前面加入一个特殊token CLS/T0
                为了区分token的顺序/token与token之间的距离，针对每个token增加一个位置向量编码（可以模型反向传播更新）
                    eg:
                        位置0/CLS/T0: [0.0, 0.0, 0.0]
                        位置1/T1: [1.0, 0.0, 0.0]
                        位置2/T2: [0.0, 1.0, 0.0]
                        位置3/T3: [0.0, 0.0, 1.0]
                        位置4/T4: [0.5, 0.5, 0.8]

                第一层Transformer Layer的计算：
                    NOTE: 头里面的WQ、WK、WV是不共享的
                    第一个头的计算:
                        将T0/T1/T2/T3/T4组成一个矩阵x[5,3]，分别乘以WQ[3,3]\WK[3,3]\WV[3,3]的参数得到q[5,3]、k[5,3]、v[5,3]
                            计算相关性: q @ k.T = attn_score[5,5] --> 每个token的query与每个token的key之间的相关性
                            转换为概率: softmax(attn_score) = attn_alpha[5,5] --> 每个token的query与每个token的key之间的权重值
                            加权合并value: attn_alpha @ v = new_v[5,3]  --> 每个token都得到了当前token对应的新的特征向量
                    第二个头的计算:
                        将T0/T1/T2/T3/T4组成一个矩阵x[5,3]，分别乘以WQ[3,3]\WK[3,3]\WV[3,3]的参数得到q[5,3]、k[5,3]、v[5,3]
                            计算相关性: q @ k.T = attn_score[5,5] --> 每个token与每个token之间的相关性
                            转换为概率: softmax(attn_score) = attn_alpha[5,5] --> 每个token与每个token之间的权重值
                            加权合并value: attn_alpha @ v = new_v[5,3]  --> 每个token都得到了当前token对应的新的特征向量

                    将所有头提取的value合并到一起, concat(new_v_head1, new_v_head2) = new_v[5,6]
                    将合并后的value做一个WO[num_head*head_dim, 3]，得到attention部分输出: new_v*wo=new_v[5,3]
                    再将new_v和输入的x进行残差合并，得到新的new_v

                    再将new_v进行FFN全连接操作 + 残差结构，得到整个Transformer模块的输出新的特征向量x[5,3]

                第二层Transformer Layer的计算: 同第一层，只是输入更改为第一层的输出
                ......

    SD扩散模型组件主要包含三个部分:
        -1. 向量提取组件(指令对应的特征向量提取):
            负责将外部数据转换为向量
                比如:
                    文本，一般是采用Bert、T5、GPT....模型；
                    一个图像/多个图像.....
        -2. VAE组件:
            编码器: 负责将原始图像转换为高阶特征向量 --> 训练UNet组件、微调训练向量提取组件
            解码器: 负责将最终UNet最终产生的预测高阶特征向量重构成原始图像
        -3. UNet组件(Image Information Creator):
            最终的功能/目的：
                输入一个随机特征向量，输出该随机特征向量包含什么噪声数据(输出值)，
                    从而得到新的随机特征向量=原始的随机特征向量-噪声数据
                不断重复/循环这个过程，从而得到最终的高阶特征向量
            NOTE: 输入包含文本向量，SD中UNet内部结构采用Transformer Block。
            NOTE: 输入除了随机的特征向量外，还可以有其它外部特征向量输入
